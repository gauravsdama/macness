# Unsigned developer build

This archive is a source/dev release convenience build for Apple Silicon Macs. It is not signed with an Apple Developer ID and it is not notarized by Apple.

macOS Gatekeeper may block or warn about the executable because its publisher cannot be verified. Review the repository, checksum, and source before deciding whether to run it. This project does not claim a frictionless installation path for unsigned binaries.

Signing and notarization are future requirements for a production binary distribution.
